# D3-1 证据等级与来源说明

## 证据等级

- **A**：ATCC 23270 同株的直接生化或遗传实验，且实验与具体模型基因/反应对应。
- **B**：当前 NCBI 基因组支持，另有独立酶学/功能来源支持同一功能，且没有未解决的位点冲突。数据库间互相引用不算独立证据。
- **C**：当前基因组/蛋白注释和功能库支持功能，尚无充分的同株基因—反应实验连接。
- **D**：其他菌株或物种结果。
- **E**：自动预测、旧assembly候选、gap-filling 或映射不确定。

本轮未将 BRENDA EC 标签自动当成某个当前 locus 的实验证明；未将 BioCyc Tier 3 的 `EV-COMP` 或 `EV-COMP-AINF` 单独升为 A/B。主表的 B/C/E 是筛选等级，均不等同于正式模型确认。A0 模型原始数值及 XML 未更改。

## 标识及版本

- 当前 NCBI 组装：`GCA/GCF_049532655.1`，`AFEATCC23270_v5.2`。B1 的新 locus tag 实际为 `RU820_RSxxxxx`。
- 旧参考的 `AFE_RSxxxxx` 与模型旧位点 `AFE_xxxx` 保留在映射列，不能因 locus tag 不同推断基因增删。
- KEGG：官方页面可见 `afr`、`Acidithiobacillus ferrooxidans ATCC 23270`、Taxonomy `243159`；KEGG记录所基于的assembly仍是旧版 `GCA_000021485.1`，作为同株的旧参考注释使用。
- BioCyc：`GCF_000021485`、PGDB 30.0，Tier 3 uncurated，2021-11-18生成，底层 RefSeq `GCF_000021485.1`。注释较新NCBI旧，不能覆盖B1。
- BRENDA：BRENDA网站标记 release `2026.1`（2026年3月）；通过 DSMZ Digital Diversity 的公开 BRENDA SPARQL prototype 读取。不同 organism record ID 按原始标签区别保留。
- Rhea：官方 REST。查询范围由 C2-1 BioCyc 反应 EC 驱动，未下载无关全库。
- MetaCyc：优先使用 C2-1 BioCyc 已有 Pathway Tools/MetaCyc reaction IDs；独立 MetaCyc 记录未另行下载，且 ID 相同仍只表示标识候选，需核实定义与化学式。

## 反应配对口径

- 优先使用 KEGG/Rhea/MetaCyc 原始标识和跨引用。
- BioCyc 基因—酶—反应关系与模型反应等价是两件事；主表明确标成 gene-associated reaction IDs，不当作方程匹配。
- Rhea 方程、ChEBI、EC、KEGG/MetaCyc cross-reference 可供化学核对；模型内部代谢物 ID 与 ChEBI 名称尚未完全映射，故未自动裁决底物、产物、化学计量、质子/电子、辅因子或方向。
- 不用 reaction name 字符串模糊判定同一反应。
