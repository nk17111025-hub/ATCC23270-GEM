# DEFERRED_MODEL_ISSUES

非阻塞问题（对“有机碳→biomass 并保留 Fe/S 能量代谢”当前目标不阻断）。均已在 Phase 1–3 诊断。

## 1. CYTRED mmc1/mmc3 质子方向相反
- 证据：mmc3.xml 为 0.5 h[c]→0.5 h[p]，mmc1.xls 为 0.5 h[p]→0.5 h[c]。
- 可能影响：ETC 质子平衡（若 CYTRED 活跃）。
- 延期原因：公开验证条件下 CYTRED 通量为 0（硫氧化走 CYTBD 分支），Phase 2.1 已裁定惰性。
- 重开触发：任何使 CYTRED 活跃的工程改造前需重新裁定方向。

## 2. CA2tpp 质量+电荷不平衡
- 证据：ca2[p] -> ca2[c] + na1[p]，Na +1、电荷 +1。
- 可能影响：Ca/Na 转运电荷与 Na 平衡。
- 延期原因：已知不确定项，当前工程目标不涉及 Ca/Na 通量定量。
- 重开触发：涉及离子转运/质子动力的工程分析。

## 3. 19 条电荷不平衡反应
- 证据：SQRED1/SULR2/PAPSR/TRDR/HCO3tpp/NDPK6/GLBRAN1/GLDBRAN2 及脂肪酸/醌类，电荷差 1–4。
- 可能影响：电荷平衡与质子相关能量计算。
- 延期原因：多为还原/氧化辅因子电荷赋值，非当前工程主线。
- 重开触发：能量/质子定量前需复核。

## 4. TSM 硫代硫酸盐摄取定量偏高
- 证据：slope 1.301，R² 0.774，6/6 实验值在最优 FVA 区间外。
- 可能影响：硫氧化供能定量。
- 延期原因：Phase 2.1 确认非 CYTRED、非 alternate optimum，是硫氧化通路真实差距；不影响有机碳工程主线的可行性判断。
- 重开触发：需要精确硫氧化能量预算时。

## 5. GPR 508 vs 507
- 证据：461 条反应非空 GPR，抽取 508 个唯一 AFE_####（论文 507）。
- 可能影响：GPR 一致性（轻微）。
- 延期原因：机械无法定位多出的 1 个 ID，需基因组基因列表比对。
- 重开触发：进行 GPR 级修复前。

## 6. ETC 质子系数不确定 / biomass 组成不确定
- 证据：CYTBD/CYTBO3 名称“2.6”但化学计量 1.8；GAM 编码 139.1（名义 139）；biomass 糖原系数借用。
- 可能影响：能量与生长定量。
- 延期原因：属后续证据审查/敏感性范围，非本阶段阻断。
- 重开触发：精确能量/生长预测前。
